# Support

For account, billing, website, or product questions, contact Krevo support through the customer portal when available.

For general public questions, open a GitHub issue only if the request does not include private account information, credentials, customer data, or security-sensitive details.

## Good Public Issues

- Documentation correction
- Broken public link
- General product question
- Public changelog clarification

## Do Not Post Publicly

- Passwords or API keys
- Billing details
- Customer data
- Private account identifiers
- Vulnerability details
- Screenshots containing sensitive information

For security reports, follow [SECURITY.md](./SECURITY.md).
