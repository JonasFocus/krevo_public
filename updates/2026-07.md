# July 2026 Update

Krevo's July update focuses on clearer product navigation, better member organization tools, and a more polished account experience. This note also catches up late-June product work that was not yet reflected in the public repository.

## Product Highlights

- Added Krevo Trees, a visual workspace for mapping ideas, projects, and notes inside the client portal.
- Expanded the personal task board with richer workflow states and priority labels.
- Refreshed the public product surfaces so visitors can more easily understand Websites, Cloud, Compute, Network, and Trees.
- Added a public product news area for announcements and release notes.
- Added a public access-request path for the compute offering.
- Rebuilt the sign-in experience and refreshed the terms and privacy pages.

## Product Focus

- Krevo continues to center on managed websites, member cloud tools, storage, support, tasks, and visual planning.
- The short-lived experimental AI assistant has been removed from the customer-facing product surface.
- The careers page now reflects that Krevo is not currently hiring.

## Notes

Krevo remains proprietary, closed-source software. This public repository contains customer-safe release notes and support references only. Private application source, deployment internals, database details, credentials, customer data, and sensitive implementation notes are not published here.
