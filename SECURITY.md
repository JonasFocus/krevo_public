# Security Policy

Krevo takes security reports seriously.

## Reporting a Vulnerability

Please report security concerns privately instead of opening a public GitHub issue.

Email: security@krevo.io

Include:

- A clear description of the issue
- Steps to reproduce, if available
- The affected URL or product area
- Any relevant screenshots or logs with sensitive data removed

## Scope

Reports should focus on Krevo-owned public surfaces and customer-facing product behavior.

Do not include customer data, secrets, credentials, private keys, or destructive proof-of-concept steps in a report.

## Disclosure

Please allow reasonable time for investigation and remediation before any public disclosure.
