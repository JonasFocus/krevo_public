# Changelog

Public-facing product updates for Krevo.

This changelog intentionally summarizes product changes without exposing private source code, infrastructure details, credentials, customer data, or internal implementation notes.

Krevo has been in active development since November 2025. This repository now serves as the public changelog for customer-safe product updates.

## 2026-06-14

Krevo shipped its largest product update yet this week. The marketing site is now public, the client portal has been rebuilt from the ground up, and cloud storage, file sharing, support, and personal task tracking are all live for members.

### Added

- **Cloud storage for members.** Upload, organize, preview, and download your files from a fast new file manager in your account. Drag and drop whole folders, move and rename in place, and recover items from trash. Large transfers keep going even on an unstable connection and pick back up where they left off.
- **Shareable links.** Create a link to any file, choose whether anyone with the link can open it or keep it restricted, and add a password when you want an extra layer of protection.
- **Personal task board.** A simple board on your dashboard to track work across To do, In progress, and Done. Drag cards between columns and add color labels to keep things organized.
- **Support with screenshots.** Attach images and files to support tickets and replies so issues are faster to explain and faster to resolve.
- **Billing history and refund requests.** Review your past charges and request a refund directly from your account.
- **New Krevo Cloud pages.** A redesigned Cloud overview and a new network page explain how Krevo keeps your work fast and secure. Krevo Cloud remains invite only, and you can request an invitation from the site.

### Improved

- **Refreshed client portal.** Your account moved to a cleaner, faster home with a new dark design, a redesigned sidebar, a usage overview, and a streamlined settings panel. Existing links continue to work.
- **Clearer plans and usage.** Your plan and storage usage now appear at a glance, so you always know where you stand.
- **Faster, more reliable uploads.** Large file transfers are more resilient and saturate your connection more effectively, with automatic retries if the network drops.

### Changed

- **The Krevo website is now public.** The pre-launch gate has been removed and anyone can browse the site and request a proposal.

### Notes

- Krevo is proprietary, closed-source software operated as a managed service. This repository contains customer-safe release notes only. Private application source, infrastructure, credentials, and customer data remain outside this repository.
