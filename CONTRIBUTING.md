# Contributing

Krevo is proprietary software and is not open source.

This public repository accepts customer-safe documentation, support, changelog, and security-process updates only. It does not accept source-code contributions to the private Krevo application.

## Acceptable Public Contributions

- Documentation corrections
- Broken public links
- Public support clarification
- Changelog wording corrections

## Not Accepted

- Application source code
- Infrastructure or deployment changes
- Database schema changes
- Private implementation notes
- Customer data
- Credentials or secrets
- Vulnerability details in public issues or pull requests

Security reports should follow [SECURITY.md](./SECURITY.md).
